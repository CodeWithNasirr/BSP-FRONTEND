# Limit Growth User Guide

**How to grow your WhatsApp messaging limit safely using the Automation + Growth Plan system.**

This guide is for business owners and operators — no technical knowledge needed. You run two things together:

- an **Automated Campaign** — sends a safe number of messages each day and picks the best contacts for you, and
- a **Growth Plan** — tracks how many genuine *quality conversations* you've built toward a higher limit.

They work together: the quality conversations your campaign produces are **automatically counted** toward your Growth Plan.

---

## 1. What this system does (the honest version)

WhatsApp (Meta) raises your limit when your messaging is **high quality** — real conversations that get delivered, read, and replied to, with very few opt-outs. It is **not** about blasting the most messages.

A **quality conversation** means:

- ✅ Message delivered
- ✅ Preferably read
- ✅ Preferably replied to
- ✅ Very low opt-out / block / failure rate

What the system does for you:

- Sends only to **opted-in, eligible, high-quality** contacts.
- Picks the **best contacts first** each day (ties broken fairly at random).
- Spreads messages across safe daytime hours.
- Watches delivery, failure, and opt-out rates and **slows down or pauses on its own** if quality drops.
- **Never exceeds** the daily number you set, and **never exceeds your current limit**.
- **Never contacts Meta** and **never promises** a limit increase. "Target limit" is only *your goal*, used to size the plan.

> In short: you set the volume and the goal; the system handles who, when, and how many — safely.

## 2. Before you start (prerequisites)

Tick these first:

```
[ ] Your WhatsApp number is connected and active
[ ] You know your CURRENT daily limit (e.g. 2,000)
[ ] You have at least one APPROVED template (ideally one that invites a reply)
[ ] If the template has an image/video/document — have that file ready to upload
[ ] You have a good list of OPTED-IN contacts (quality matters more than size)
```

---

## 3. Step-by-step setup

### Step A — Prepare your contacts (best 5,000–15,000 first)

Do **not** use your entire list. Start with your **best** contacts.

```
[ ] Import or clean your contacts
[ ] Build a segment or group of your BEST contacts (recent buyers, people who
    reply, engaged customers)
[ ] Aim for 5,000–15,000 quality contacts for the first campaign
[ ] Keep cold / unknown / very old contacts for later (or not at all)
```

### Step B — Create the Automated Campaign

Go to **Automation → New automated campaign**. The wizard has 4 short steps:

```
[ ] 1. Audience — name it clearly (e.g. "Growth 2k to 10k"); pick your pool
       (segment / group / all / single). The wizard shows how many contacts are in it.
[ ] 2. Template — pick an approved template. If it needs an image/video/document,
       upload it here. If it has {{1}}, {{2}} placeholders, map each to a contact
       field or a fixed value.
[ ] 3. Volume — set Daily target = 100 (start LOW). Turn ON "Warm up gradually"
       (recommended) so it ramps up over several days.
[ ] 4. Review & Start.
```

After starting, open the **Control Panel** — it tells you exactly when the first messages will go out ("Today's batch is ready — sending starts at ~09:00…").

### Step C — Create the Growth Plan

Go to **Automation → Growth plans → New plan**.

```
[ ] Current limit  — your limit today (e.g. 2,000)
[ ] Target limit   — your goal (e.g. 10,000)  ← sizing only, not a promise
[ ] Quality conversations needed — e.g. 1,000
[ ] Planning days  — e.g. 7–10
[ ] Minimum contact quality — "High only" (strictest) to start
[ ] Require a reply — leave ON (a reply is the strongest signal)
[ ] Create & start
```

### Step D — Let them run together

That's it. The campaign sends each day; every quality conversation it produces is **counted automatically** toward your Growth Plan. You don't message anyone by hand.

```
[ ] Campaign is RUNNING (Automation dashboard)
[ ] Growth Plan is ACTIVE (Growth plans)
```

## 4. Daily operating checklist

Spend 2–3 minutes each day.

**On the Automation Dashboard:**
```
[ ] Sent today vs target — is it sending?
[ ] Success rate — is it high?
[ ] Status line under the campaign — what's happening right now?
[ ] Any automatic pauses? Read the reason.
[ ] Any alerts? Read and clear them.
```

**On the Growth Plan (open your plan):**
```
[ ] X of Y quality conversations — is progress moving?
[ ] Account health — Delivery / Failure / Opt-out looking good?
```

**Then decide the day's action:**

| Situation | What to do |
|---|---|
| Success rate high + opt-outs low | **Increase** daily volume by a small step (+30–50) |
| Quality steady but not great | **Keep** the same volume another day |
| Success rate dropping / opt-outs rising | **Lower** the daily volume |
| System auto-paused, or failures spiking | **Pause**, check the template/audience, resume when healthy |
| Template getting few reads/replies | **Change the template** (no need to stop the campaign) |

**Golden rule: increase slowly, decrease quickly.** When unsure, hold for another day.

You can also **edit the remaining daily targets** on the Growth Plan (upcoming days only) — the system re-balances automatically if you're ahead or behind.

## 5. Recommended starting numbers (2,000 → 10,000 example)

| Setting | Value |
|---|---|
| Contact pool | Best 5,000–15,000 |
| Daily target (Day 1) | 80–120 |
| Warm-up | ON (7–10 days) |
| Quality conversations goal | ~800–1,200 |
| Plan length | 7–10 days |
| Sending hours | 09:00–20:00 |

**Suggested day-by-day volume:**

| Day | Daily volume | Only if… |
|---|---|---|
| 1 | 80–100 | always start here |
| 2 | 120–150 | Day 1 success was high |
| 3 | 150–180 | quality still good |
| 4 | 180–220 | quality still good |
| 5 | 220–250 | quality still good |
| 6 | 250–280 | quality still good |
| 7 | 280–300 | quality still good |
| 8+ | hold ~300 | increase only if quality stays excellent |

> Growing later (10k → 100k): go **slower**, use your best segments first, and split large lists into quality tiers (High engagers → Recent customers → Medium → Cold).

---

## 6. Safety rules (please follow)

```
[ ] Always start low (80–120/day)
[ ] Never jump volume aggressively — small steps only
[ ] Watch success rate and opt-outs every day
[ ] Respect the system's auto-pause — fix the cause before resuming
[ ] Prefer templates that get replies
[ ] Use your best contacts first, cold contacts last (or never)
[ ] Quality over quantity — always
```

The system already protects you: it never exceeds your daily number or your current limit, and it pauses itself if health drops.

---

## 7. What you should NOT do

```
[ ] ❌ Do NOT put all 100,000 contacts into one campaign
[ ] ❌ Do NOT start with a high daily volume "to go faster"
[ ] ❌ Do NOT lead with cold, unknown, or very old contacts
[ ] ❌ Do NOT ignore an auto-pause — it means quality dropped
[ ] ❌ Do NOT keep pushing a template that gets no reads/replies
[ ] ❌ Do NOT try to message opted-out contacts (the system blocks this — never
       try to force it)
[ ] ❌ Do NOT expect an instant limit jump — quality adds up over days
```

---

### Remember

Set a **modest daily volume**, turn on **warm-up**, create a **Growth Plan**, and let them run. Check once a day, raise volume only when quality is strong, and trust the auto-pause. Steady, high-quality conversations are what grow your limit — safely.
